# 💿 RecordCraft

**Your Music. Your Records. Your Minecraft.**

RecordCraft brings your own music collection into Minecraft.

Create custom vinyl records from music stored on your computer, design album covers, record complete albums and play them using interactive turntables with positional audio.

Want to take your music with you? Equip a Discman and headphones and keep listening while exploring your world.

## ✨ Features

- 💿 Custom vinyl records and albums
- 🎨 Custom album covers
- 🎵 MP3, WAV and M4A playback
- 📚 Configurable local music library
- 🎙️ Interactive Vinyl Recorder
- 🎚️ Interactive Vinyl Players
- 🔊 Positional audio
- 🔊 Multiple simultaneous audio sources
- 🎧 Portable Discman
- 🎧 Equipable headphones
- 🌈 16 headphone colors
- 🪵 Multiple wood variants for Vinyl Players and Vinyl Recorders
- 🎛️ Configurable playback HUD
- 💾 Playback persistence and resume
- ⏹️ Automatic stop at the end of an album
- 🇺🇸 English localization
- 🇲🇽 Mexican Spanish localization

## ⌨️ Controls

- **F6** — Playback and HUD settings
- **F7** — Music library

Key bindings can also be changed from Minecraft's Controls settings.

## 📋 Requirements

- Minecraft Java Edition **26.3**
- Fabric Loader **0.19.5+**
- Fabric API
- Java **25**

## 💻 Platform Support

RecordCraft is designed for desktop Minecraft Java Edition.

Windows has been tested directly.

Linux and macOS support is intended through the included native libraries, but these platforms have not yet been fully tested.

Mobile Java launchers on Android and iOS are not officially supported.

## 🎵 Music Files

RecordCraft does not include, host, download or distribute music.

Music is selected from files stored locally on the player's computer. Users are responsible for ensuring they have the appropriate rights to any music they use.
